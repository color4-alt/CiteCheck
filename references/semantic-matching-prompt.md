# 语义匹配度评估 Prompt

## 用途

评估论文正文中引用片段与引文原文内容之间的语义一致性。

## Prompt 模板

```
你是一个文本语义匹配专家。请计算以下两段文本的语义匹配度。

【评分标准】
- 1.0：语义完全相同（表达的意思彻底一致）。
- 0.8：语义高度相似（主要核心意思一致，仅有个别词汇或修饰语差异）。
- 0.5：语义部分相关（讨论的是同一主题，但具体观点、角度或细节不同）。
- 0.2：语义基本无关（仅有极少数宽泛的词汇重合，核心意思完全不同）。
- 0.0：完全无关（没有任何关联）。

【待评估文本】
文本 A（论文正文中的引用内容）："{citing_text}"
文本 B（引文原文中的对应内容）："{cited_text}"

【输出格式】
请直接给出评分（0.0 到 1.0 之间的数字），并用一句话简要说明理由。
```

## 使用说明

1. 从论文正文中提取引用处上下文（通常包括引用标记前后的 1-2 句话）
2. 从引文全文中定位最可能对应的段落（可通过标题、关键词匹配或全文检索）
3. 将两段文本填入模板，调用 LLM 评估
4. 记录评分和理由，用于最终报告

## 注意事项

- 如果引文原文无法获取，标记为 "原文不可达"
- 如果引用的是数据/实验结果，重点关注数值和结论的一致性
- 如果引用的是方法论，关注方法描述是否准确
