# 语义匹配度评估 Prompt

## 用途

评估论文正文中引用片段与引文原文内容之间的语义一致性。

## Prompt 模板

```
【评分标准】
- 1.0：语义完全一致（引用内容准确反映了原文）
- 0.8：高度一致（核心含义匹配，细节略有差异）
- 0.5：部分相关（同一主题，但引用对原文有过度推断或断章取义）
- 0.2：弱相关（勉强沾边）
- 0.0：无关或矛盾（引用内容与原文相悖）

Text A（引用上下文）：{citing_text}
Text B（引文摘要）：{cited_text}

请给出 0.0-1.0 的评分，并用一句话说明理由。
```

## 使用说明

1. 从论文正文中提取引用处上下文（通常包括引用标记前后的 1-2 句话）作为 `citing_text`
2. 通过 Semantic Scholar 或 WebSearch 获取引文摘要作为 `cited_text`
3. 将两段文本填入模板，调用 LLM 评估
4. 记录评分和理由，用于最终报告

## 注意事项

- 如果引文原文无法获取，标记为 "source unreachable"
- 如果引用的是数据/实验结果，重点关注数值和结论的一致性
- 如果引用的是方法论，关注方法描述是否准确
